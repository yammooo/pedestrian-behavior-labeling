# Decision records

Create a record only when a material choice is accepted. Use:

```markdown
# Decision

Date:
Status: Proposed | Accepted | Superseded

## Context
## Decision
## Alternatives considered
## Evidence / rationale
## Consequences
## Revisit if
```
