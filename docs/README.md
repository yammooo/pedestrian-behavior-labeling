# Research dashboard

Updated **2026-11-12**. We are developing a reliable **offline, given-track pedestrian behavior labeler**. Final architecture and publication contribution remain provisional. Deadline **17 December 2026**; **7–17 December** is protected for buffer and handover. The [literature review](literature/offline-labeling-research-direction.md) supports an empirical study first, with one conditional retrieval or supervision comparison.

## Current evidence

- **[E002a/E002b comparison](../experiments/E002b-normalization-capacity/results-review.md):** 26 selected seed0 source-validation models, plus a five-seed E002a RGB summary (**58.12% ±0.90 pp ROAD /66.74% ±0.50 pp LOKI**). Smaller-temporal geometry + LiDAR reaches **66.05% ROAD /76.41% LOKI** at seed0. [E002c](../experiments/E002c-rgb-regularization/README.md) finds no consistent gain from stronger temporal dropout, while RGB branch dropout raises seed0 validation F1 by up to2.08 pp ROAD /0.57 pp LOKI. The [joint regularization comparison](../experiments/E002-multimodal-reference/README.md#single-axis-regularization-comparison-2026-11-03) puts these beside E002e weight decay. Three LOKI LiDAR trainings remain interrupted with evaluated best checkpoints. Held-out tests remain closed; exploratory cross-validation transfer is recorded below.
- **[E002d fusion comparison](../experiments/E002d-rgb-lidar-complementarity/results-review.md):** Four completed seed0 source-validation runs. RGB dropout 0.5 yields **66.07% ROAD / 74.68% LOKI** F1, versus the smaller-temporal geometry + LiDAR control's **66.05% / 76.41%**; selected CE is slightly higher. Fusion without RGB dropout is lower on both. All four fusion runs retain large train/validation gaps. The LOKI control is an evaluated checkpoint from interrupted training; held-out tests remain closed.
- **[E002e weight-decay check](../experiments/E002e-weight-decay-sensitivity/README.md#results):** Four seed0 `g-rgb / temporal-small` runs are complete. Weight decay0.01/0.1 does not improve selected F1 over0.0001;0.1 modestly reduces terminal CE divergence, while the train/validation F1 gap remains large. The final WD1.0 run per source is ready to launch using the accepted existing profile; source validation only.
- **[E002 cross-dataset validation](../experiments/E002-multimodal-reference/transfer-results.md):** Eight source-normalized seed0 evaluations complete. Fusion leads ROAD→LOKI F1 (**46.50%**); RGB leads LOKI→ROAD (**46.33%**). Source-to-opposite-validation F1 drops16.61–33.00 pp; LiDAR's leading source F1 does not imply leading transfer F1. The [class-conditioned motion diagnostic](../experiments/E002-multimodal-reference/transfer-results.md#class-conditioned-statistics-and-transfer-failures) finds a large Crossing transfer gap even within a shared speed bin. Both validation sets informed development; held-out tests remain closed.
- **[E001/E001b/E001c review](../experiments/E001b-2d-bbox-contribution/results-review.md):** 130 completed five-seed attempts /260 held-out cells. BiLSTM improves over the original smaller MLP; bbox geometry helps transfer in one direction; replacement native-box inputs and size velocities provide no consistent gain. These test results informed later development. The completed [E001d capacity control](../experiments/E001d-temporal-capacity-control/README.md#results) retains a BiLSTM advantage in three directions, while LOKI→ROAD means are nearly tied.
- **[Data and pretrained features](../experiments/E002a-feature-feasibility/README.md):** frozen populations/splits,3× DINO crops and indexed D-DITR features remain unchanged. The [packed spatial-readout benchmark](../experiments/E002a-feature-feasibility/README.md#packed-spatial-readout-benchmark--2026-10-29) rejects one segmented PyTorch implementation: model updates are 2.15–2.25× slower on matched ROAD/LOKI inputs. Earlier native/PCA/semantic probes, storage revisions, throughput measurements and failures stay in that owner. [ROAD split verification](datasets/road-waymo.md#official-download-verification-2026-10-16) retains the documented paper/release mismatch; experiment splits remain frozen.
- **[Prediction viewer](../README.md#inspect-model-predictions):** compares E001-family test and E002/E003 validation predictions, including direct transfer, target adaptation and E002f architectures. The [E002a RGB seed curves](../experiments/E002a-feature-feasibility/README.md#geometry--rgb-repeat--seeds-14-prepared-2026-10-28) show online training F1 and source validation for eight completed repeats; historical seed0 has no training-F1 curve.

- **[E003a structured observation masking](../experiments/E003a-structured-observation-masking/README.md#results):** both seed0 attempts complete. Against matched E002d controls, natural ROAD→LOKI validation F1 falls **46.50%→40.26%**, while LOKI→ROAD is nearly unchanged (**45.02%→45.28%**). Source F1 changes **66.07%→65.46% ROAD /74.68%→76.08% LOKI**. Several fixed missing-input diagnostics improve, but this sampler does not show a consistent natural-transfer gain; overfitting remains in both sources. Curves and diagnostics stay in the experiment owner. Target-informed validation development; held-out tests remain closed.
- **[E003b target-head adaptation](../experiments/E003b-target-head-adaptation/README.md#results):** four seed0 attempts complete. With the complete source-trained body frozen, a new target-trained linear head raises validation F1 from40–47% to63–64% on LOKI and45% to59–60% on ROAD. Against same-family models trained on the target, remaining gaps are **10.52–13.32pp ROAD→LOKI /4.97–6.58pp LOKI→ROAD**; source-versus-target score similarity is not a transfer-gap measure. E003a has no consistent adaptation advantage. Two heads reach the100-epoch budget. Full target-label access and changed normalization/training qualify the comparison; recovery does not isolate annotation mismatch. Tests remain closed.

- **[E003b embedding diagnostic](../experiments/E003b-target-head-adaptation/README.md#diagnostic-results):** pooled PCA and UMAP of both original E002d bodies on both validation datasets are complete. UMAP shows dataset-dominated neighborhoods across the checked seeds/settings despite shared broad behavior structure; recoverable target information does not imply dataset invariance. No adaptation training or test access.
- **[E003c source-checkpoint fine-tuning](../experiments/E003c-temporal-adaptation/README.md#full-source-initialized-results-2026-11-06):** both ROAD→LOKI seed0 full runs start from the original E002d head (46.50% validation F1). Fine-tuning temporal blocks + final LayerNorm reaches **68.17% F1**, +4.27 pp over head-only, but selected CE is slightly higher (**0.52458 vs0.51994**); validation CE bottoms at e21 then rebounds, with a large online-train/validation gap. Full target-label access and validation selection; tests remain closed.
- **[E002f temporal architecture](../experiments/E002f-temporal-architecture/README.md):** all six full runs complete. Direct ROAD→LOKI F1 is **44.03% one-layer Transformer /45.01% BiLSTM /46.50% two-layer reference**; temporal/head adaptation reaches **66.72% /67.73% /68.17%**. Smaller models remain competitive without a consistent F1 advantage. Per-class scores, confusion matrices and curves are recorded; seed0, full target-label adaptation and validation selection only. Tests remain closed.
